version: 1.0
triggers: 插件没有执行,插件未触发,插件没触发,插件没运行,为什么插件不执行
required-tools: list_current_entity_plugin_steps
---

只检查当前实体相关的自定义步骤。核对消息、启用状态、阶段、同步模式、顺序和过滤字段；必要时读取已确认步骤的插件实现，判断代码是否存在提前返回条件。

必须区分“步骤未被触发”和“步骤触发后没有产生用户预期结果”。没有插件跟踪日志时，不要声称某次执行已经或没有进入代码。
